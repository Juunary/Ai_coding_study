# 검색 기반 표면 타입 확장 (설계 초안)

사전학습된 세그멘테이션과 기존 피팅 코드를 그대로 두고, Point2CAD가 지원하는 표면 타입을 늘리기 위한 설계 메모와 코드 초안입니다. 기존 파일은 수정하지 않았고 이 폴더의 파일만 새로 추가했습니다.

## 1. 타입 선택 로직 위치

`fitting_one_surface.py`의 `process_one_surface()`:

| 단계 | 내용 |
|---|---|
| 기본 프리미티브 피팅 | `fit_basic_primitives()` (평면, 구, 원기둥, 원뿔) |
| 자유곡면 피팅 | `fit_inrs()` |
| 타입별 오차 계산, 무효 처리 | 오차를 `np.inf`로 처리 |
| 최종 선택 | `[plane, sphere, cylinder, cone, inr]` 오차 배열의 `argmin` + 기본 프리미티브 우선 규칙 |
| 메쉬, `pred_info` 생성 | 선택된 타입별 분기 |

입력은 이미 라벨링된 `.xyzc` 파일이고(`main.py`), 세그멘테이션은 이 파이프라인 밖에서 만들어집니다. 타입은 학습된 분류기가 아니라 **피팅 후 오차 비교**로 정해집니다.

선택 규칙 요약:
- INR 오차가 가장 작아도, 기본 프리미티브 최소 오차가 0.008 미만이면 기본 프리미티브를 선택
- 기본 프리미티브 최소 오차가 INR 오차 + 0.001 미만이어도 기본 프리미티브를 선택
- 원뿔 오차가 평면 오차와 1e-5 이내면 평면으로 처리

## 2. 타입을 추가하려면

1. `fit_basic_primitives()`에 새 피팅과 오차, 파라미터 추가
2. 오차 계산부에 무효 처리 규칙 추가
3. 선택부와 분기부 수정. 현재는 타입을 **정수 인덱스**로 다루고(INR이 4번 등) 기본 프리미티브 4개를 직접 나열한 곳이 여러 군데라, 타입이 늘면 함께 고쳐야 함 -> `select_type.py`처럼 타입 이름 기반으로 바꾸는 것을 권장
4. `visualize_basic_mesh`, 클리핑, 위상 계산(`io_utils.py`, `primitive_utils.py`)이 새 타입을 처리하는지 확인

## 3. 검색 기반으로 후보 좁히기

LLM의 RAG를 점군에 맞게 바꾼 방식입니다. 생성 단계가 없으므로 정확한 명칭은 retrieval-based classification(kNN 기반 few-shot 분류)입니다.

| LLM RAG | 여기서의 대응 |
|---|---|
| 질문 | 표면 클러스터 하나 |
| 문서 DB | 타입별 예시 면 모음 |
| 임베딩 모델 | 점군을 벡터로 바꾸는 고정 인코더 |
| 유사 문서 검색 | 유사 예시 면 검색(kNN) |
| 답 생성 | 이웃의 타입으로 **후보 타입 집합**을 결정 |

흐름:
1. 타입별 합성 패치를 수식으로 대량 생성(노이즈, 부분 관측 포함) -> 인코더로 임베딩 -> `(벡터, 타입)` 저장
2. 입력 클러스터를 임베딩해 top-k 이웃의 타입을 투표 -> 후보 집합
3. 후보 타입만 피팅하고 기존 오차 규칙으로 최종 선택(후보가 아닌 타입의 오차는 `inf`)

새 타입 추가 = 예시 임베딩 추가 + 해당 타입의 피팅 모듈 구현. 인코더와 세그멘테이션은 재학습하지 않습니다.

## 4. 한계

- 검색은 분류만 도와줍니다. 새 타입의 **면 생성(피팅), 교차선 계산은 별도 구현**이 필요합니다.
- 합성 데이터와 실제 스캔 사이의 도메인 차이가 큽니다.
- 인코더가 새 타입을 구분하지 못하면 검색이 틀립니다.
- 세그멘테이션이 새 타입 영역을 하나로 묶어주지 못하면 소용없습니다.

## 5. 이 폴더의 파일

- `select_type.py`: 기존 선택 규칙을 타입 이름 기반으로 옮기고 후보 마스킹을 지원하는 초안
- `retrieval_candidates.py`: kNN 투표로 후보 타입을 뽑는 최소 구현
- `test_select_type.py`: 기존 규칙과의 동작 일치 및 신규 타입, 후보 마스킹 확인

아직 `fitting_one_surface.py`에는 연결하지 않았습니다.

## 6. 검증 계획

기존 타입 하나(예: 원뿔)를 예시 DB에서 빼고 재학습 없이 다시 추가해, 처음부터 포함했을 때와 성능이 비슷한지 비교합니다. 비교 대상은 (a) 오차만 쓰는 기본 방식, (b) 분류기 파인튜닝, (c) 검색 + 피팅 검증이고, 지표는 타입 정확도와 Chamfer distance입니다.
