# 도형 임베딩 모델과 검색 기반(RAG식) 타입 추론

표면 클러스터(점군)를 임베딩 벡터로 바꾸고, 타입별 예시 벡터를 DB에 저장해 둔 뒤, 새 클러스터가 들어오면 가장 비슷한 예시를 검색해 도형 타입을 추론합니다. 모든 코드는 numpy만 사용합니다.

```
XYZ 점군
  │ shape_elements.py   XYZ → 도형 요소(법선, 주곡률, shape index, ...) → 87차원 기술자
  ▼
기술자
  │ shape_encoder.py    MLP(87→64→32, triplet loss 학습) + 기술자 원본을 이어 붙여 정규화
  ▼
임베딩 벡터
  │ shape_rag.py        벡터 DB에서 kNN 검색 → 유사도 가중 투표 → 후보 타입 (유사도가 낮으면 unknown)
  ▼
후보 타입 ── (선택) 피팅 오차로 최종 검증: select_type.select_surface_type(errors, candidates)
```

## 1. XYZ를 도형 요소로 표현 (`shape_elements.py`)

XYZ 좌표는 위치, 회전, 크기에 따라 값이 바뀌므로 그대로 비교할 수 없습니다. 그래서 각 점을 그 점 주변 곡면의 **기하 요소**로 다시 표현합니다. 아래 요소는 모두 위치, 회전, 크기에 무관합니다.

| 요소 | 계산 | 평면 | 구 | 원기둥 | 원뿔 | 토러스 |
|---|---|---|---|---|---|---|
| 법선 | 이웃 32점 PCA의 최소 고유벡터 | 전부 동일 | 방사형 | 축에 수직 | 축과 일정 각도 | 다양 |
| 주곡률 k1, k2 | 접평면 좌표계에서 2차 곡면 강건 피팅 → 제1·2 기본형식 | 0, 0 | 1/R, 1/R | 1/R, 0 | 위치마다 변함, 0 | 두 값이 다름 |
| shape index (절댓값) | (2/π)·atan((k1+k2)/(k1−k2)) | (정의 안 됨) | 1 | 0.5 | 0.5 | 0~1 혼재 |
| 가우스 곡률 부호 | K / curvedness² | 0 | +1 | 0 | 0 | 바깥 +, 안쪽 − |
| curvedness | √((k1²+k2²)/2) | ≈0 | 일정 | 일정 | 축 따라 변함 | 두 크기 |
| 법선 텐서 고유값 | 평균(n·nᵀ) | (0, 0, 1) | 고르게 분산 | 최소값 ≈ 0 | 최소값 = sin²α | 분산 |
| 법선 정렬도 | 법선 텐서 축과 각 법선의 내적 | | | 축 성분 0 | 축 성분 일정 | |

기술자(87차원)는 위 요소의 분포를 요약한 것입니다. 구성은 curvedness×가우스부호 2D 히스토그램(36), shape index(8), 가우스부호(8), 법선 정렬도 3축(18), surface variation(6), 법선 텐서 고유값(3), 점 분포 고유값(3), 곡률 통계(5)입니다.

실제 데이터에서 문제가 된 점과 대응은 다음과 같습니다.
- **테두리 오염**: `casing_001` 라벨 1, 4는 얇은 링 모양 평면인데, 테두리에 인접 면의 점이 섞여 있었습니다. 일반 최소제곱으로 곡률을 구하면 평면이 원뿔이나 토러스로 오분류됐습니다. 그래서 곡률 피팅을 IRLS(Cauchy 가중)로 바꿨습니다.
- **곡률 변동계수 폭주**: 평면은 곡률 평균이 약 0이라 `표준편차/평균`이 폭주했습니다(실제 4.46, 합성 최대 0.69). 분모에 0.1을 더했고, 표준화한 기술자 값은 ±5로 자릅니다.

## 2. 임베딩 모델 (`shape_encoder.py`)

- 구조: 기술자 표준화(±5 클립) → MLP(87→64, ReLU→32) → L2 정규화
- 학습: batch-hard triplet loss(margin 0.3, Adam). 같은 타입은 가깝게, 다른 타입은 멀게 학습합니다.
- 최종 임베딩: `[학습 벡터 32차원, raw_weight × 표준화 기술자 87차원]`을 이어 붙여 정규화합니다.
  - 학습 벡터는 학습한 타입들을 날카롭게 구분합니다.
  - 기술자 원본을 함께 넣은 이유는 **학습에 없던 타입**에 필요한 정보를 MLP가 버리지 않게 하려는 것입니다. 개발 중 실험에서 학습 데이터가 적을 때(타입당 40개) 토러스 인식률이 0.90에서 1.00으로 올랐습니다(`raw_weight=1.0`).

합성 학습 데이터(`shape_synth.py`)는 실제 세그멘테이션 클러스터와 비슷하게 만듭니다. 크기, 각도 범위, 자세, 점 개수(150~1000)를 무작위로 정하고, 평면은 직사각형과 링 모양을 섞습니다. 30%는 노이즈가 없고(CAD 샘플 데이터 대응) 나머지는 노이즈 0~2%입니다. 30%에는 테두리 오염(인접 면 방향으로 꺾인 점 2~10%)을 넣습니다.

## 3. 벡터 DB와 검색 (`shape_rag.py`)

- `ShapeVectorDB`: (임베딩, 타입) 저장, 코사인 kNN 검색, `exp(sim/0.1)` 가중 투표, npz로 저장하고 불러오기
- `infer_shape_type(points, encoder, db, errors=None, min_similarity=None)`
  - 가장 가까운 예시의 유사도가 `min_similarity`보다 낮으면 `unknown`을 반환합니다(CLI 기본값 0.8).
  - `errors`가 없으면 최다 득표 타입을 반환합니다.
  - `errors`(fitting_one_surface.py의 타입별 피팅 오차, `"inr"` 포함)를 주면 득표율 20% 이상인 후보만 남기고 기존 오차 규칙으로 최종 선택합니다.

**새 타입 추가 = 그 타입의 예시 패치를 임베딩해 DB에 넣기**입니다. 인코더는 재학습하지 않습니다. 실제 면을 만들려면 그 타입의 피팅 모듈은 따로 구현해야 합니다. 검증된 실제 클러스터를 DB에 예시로 추가하면 합성-실제 차이를 줄일 수 있습니다.

## 4. 사용법

```bash
cd point2cad/point2cad/retrieval_extension
python build_shape_db.py --out artifacts          # 학습 + DB 생성 + 평가 (약 2분, CPU)
python infer_shape.py --path_in ../../assets/ply/shaft/xyzc/shaft_001.xyzc
python test_shape_rag.py                           # 테스트
```

`artifacts/`에는 학습된 인코더(`shape_encoder.npz`)와 DB(`shape_db.npz`)가 들어 있어서 바로 추론할 수 있습니다.

`fitting_one_surface.py`와 연결하는 예시입니다(기존 파일은 수정하지 않았습니다).

```python
from shape_encoder import ShapeEncoder
from shape_rag import ShapeVectorDB, infer_shape_type

enc = ShapeEncoder.load("retrieval_extension/artifacts/shape_encoder.npz")
db = ShapeVectorDB.load("retrieval_extension/artifacts/shape_db.npz")

errors = {"plane": plane_err, "sphere": sphere_err, "cylinder": cylinder_err,
          "cone": cone_err, "inr": inr_err}
r = infer_shape_type(in_points.cpu().numpy(), enc, db, errors=errors, min_similarity=0.8)
# r["type"], r["similarity"], r["candidates"], r["votes"]
```

## 6. 한계

- **정량 평가는 합성 데이터뿐**입니다. 실제 데이터는 정답 라벨이 없어 기하 검사로만 확인했습니다.
- **`unknown` 판정은 부분적입니다.** 임계값 0.8에서 섞인 클러스터의 41%만 걸러냅니다. 입력은 세그멘테이션된 **단일 면**이라고 가정합니다.
- **DB에 없는 자유곡면이나 압출면**(임펠러 날개 등)은 가장 가까운 해석적 타입으로 분류되고, 그 결과는 학습 시드에 따라 달라집니다. 피팅 오차 검증(`errors` 인자)과 INR 대체를 함께 써야 합니다. 자유곡면 예시를 DB에 넣는 확장도 고려할 수 있습니다.
- 학습에 없던 타입은 토러스로만 검증했습니다. 인식률은 학습 데이터 양과 `raw_weight`에 영향을 받습니다.
- 개발 과정에서 실제 데이터를 보고 기술자와 합성 데이터를 조정했습니다(IRLS, 변동계수 보정, 테두리 오염, 노이즈 없는 패치). 따라서 위 실제 데이터 결과는 독립적인 테스트가 아니며, 다른 실제 데이터로 따로 확인해야 합니다.
